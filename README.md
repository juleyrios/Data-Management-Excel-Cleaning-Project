# Data Management Excel Cleaning Project

A complete data auditing and transformation project using Microsoft Excel. This repository showcases the process of taking a raw, unorganized sales transaction log—plagued with text casing errors, text-stored numbers, inconsistent date formats, missing values, and duplicate records—and standardizing it into an analysis-ready workbook.

**Key Features & Highlights:**

Data Normalization: Cleaned and formatted strings using TRIM, PROPER, and custom text replacement functions.

Deduplication & Validation: Removed duplicate transaction IDs and established input validation rules.

Automated Metrics: Generated dynamic PivotTable reports and key summary metrics by category and order status.
